# 毛雨晴 · AI 产品体验与内容作品集

面向 AI 产品体验、内容运营方向的独立版本。首页优先展示公众号、小红书和 AI 实践，其后为实习经历与完整项目；原站点保持不变。

- 原站：https://mon24123.github.io/portfolio/
- GitHub Pages：https://mon24123.github.io/portfolio-studio/
- 主要页面：`dist/index.html`
- 样式：`dist/style.css`
- 图片查看、主题切换与打印：`dist/app.js`
- 原有路见公开案例：`dist/bp.html`
- 内容来源与事实边界：`SOURCE_NOTES.md`

使用任意静态 HTTP 服务预览 `dist` 目录，无构建依赖。经本人授权，仓库与 GitHub Pages 公开。`.github/workflows/deploy-pages.yml` 将 `dist` 发布到 GitHub Pages，main 分支的网页改动自动部署，也可手动运行。Sites 发布配置位于 `.openai/hosting.json`，原 Sites 私人预览独立保留。

页面展示碳循花园、GLIM、企业参访、路见和好时光，随后呈现运营经历与个人介绍。好时光沿用本人旧 AI 产品作品集中的功能示意图，其余图片来自原作品集；没有使用参考作品集的图片，也没有生成虚构项目素材。
